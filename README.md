## 📄 Documentation Standards

Every project in this portfolio follows a structured QA process:

```
📋 System Analysis       → Understanding the application under test
📝 Test Plan             → Scope, strategy, entry/exit criteria
🧪 Manual Test Cases     → Step-by-step test cases with expected results
🤖 Test Automation       → Scripts following industry-standard patterns
⚙️  CI/CD Pipeline       → GitHub Actions running tests on every push
📊 Test Reports          → HTML reports with screenshots on failure
```
